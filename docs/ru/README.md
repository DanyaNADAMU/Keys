# Документация Keys (Русский)

Этот каталог содержит руководства и справочные материалы по верификации криптографических открытых ключей и сертификатов, опубликованных в репозитории.

## Руководства по верификации

- **Подписи коммитов Git**: Проверка подписей коммитов и тегов через OpenSSH `allowed_signers` (`.allowed_signers` или `ssh/allowed_signers`).
- **OpenPGP**: Импорт и проверка открытых ключей PGP из каталога `pgp/danya.asc`.
- **S/MIME**: Валидация сертификатов X.509 и цепочек доверия для шифрования и подписи почты из `smime/danya.crt`.
- **OpenTimestamps**: Проверка криптографических меток времени в блокчейне Bitcoin с помощью `git ots verify`.
- **Политика безопасности**: Контакты для отчётов об уязвимостях и параметры RFC 9116 в файле `security/security.txt`.
