The NadaMu Cloud application integrates with the Google Drive API to provide automated, encrypted backup synchronization and file storage capabilities.

  • Область доступа (Scope)Requested Scope: https://www.googleapis.com/auth/drive.file. Приложение запрашивает доступ исключительно к тем файлам и папкам, которые были созданы самим приложением. Доступ к вашим остальным персональным файлам на Google Диске отсутствует. The application requests access strictly to files and folders created or opened by the application itself. It possesses no access to any other personal files stored on your Google Drive.

4. Сквозное шифрование и безопасность данных 4. Client-Side Encryption & Security

Вся информация перед отправкой в удаленное облачное хранилище защищается средствами клиентского сквозного шифрования (Rclone Crypt). Имена файлов, структура каталогов и содержимое блоков шифруются симметричными криптографическими алгоритмами высокой стойкости на стороне сервера-источника. Google получает исключительно зашифрованный массив байт, расшифровка которого без ваших мастер-ключей математически невозможна. All data synchronized to remote cloud storage undergoes rigorous client-side end-to-end encryption (Rclone Crypt). File names, directory hierarchies, and payload bytes are encrypted with strong symmetric ciphers on the source server before egress. Cloud providers only receive opaque ciphertext blobs, making unauthorized inspection mathematically infeasible without private decryption keys.
